# SoftFlesh.js v1.0.0 - мягкие деформации для веб-игр на Three.js

Подключаемая JS-библиотека, которая добавляет 3D-моделям живые мягкие деформации: вмятины и выпуклости от касаний, сплющивание, надувание, инерционную тряску «жира/желе», волны от ударов и взаимодействие мягких тел в реальном времени.

Внешняя зависимость одна - Three.js (>= 0.150), физический движок не обязателен.
